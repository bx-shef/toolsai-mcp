# toolsai-mcp

> Last reviewed: 2026-10-14

MCP-сервер для Битрикс24: внешний ИИ (Claude и другие MCP-клиенты) читает сделки,
лиды, контакты, дела и задачи **любого** Битрикс24 — облачного или коробочного — **от имени конкретного сотрудника и в рамках его прав**.

- Вход — OAuth 2.1 (PKCE, динамическая регистрация клиента): сервер сам выступает сервером
  авторизации, а внутри отправляет сотрудника войти в его Битрикс24 (адрес вводит сотрудник).
- Вызовы REST идут токеном сотрудника — права Битрикс24 соблюдаются сами.
- Встроенные инструменты — только чтение. Свои модули портала добавляют инструменты сами, через
  манифест (`docs/MODULE_TOOLS.md`); запись и удаление — только сотрудникам из `WRITE_USERS`.
- Docker (Nuxt + `@nuxtjs/mcp-toolkit` + Redis) на VM портала, снаружи — путь `/mcp-ai/` через nginx портала.
