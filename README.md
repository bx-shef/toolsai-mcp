# toolsai-mcp

> Last reviewed: 2026-10-13

MCP-сервер для коробочного Битрикс24: внешний ИИ (Claude и другие MCP-клиенты) читает сделки,
лиды, контакты, дела и задачи портала **от имени конкретного сотрудника и в рамках его прав**.

- Вход — OAuth 2.1 (PKCE, динамическая регистрация клиента): сервер сам выступает сервером
  авторизации, а внутри отправляет сотрудника войти в портал через локальное приложение Битрикс24.
- Вызовы REST идут токеном сотрудника — права Битрикс24 соблюдаются сами.
- Сейчас только чтение; запись — отдельным шагом (`docs/project-map.md`).
- Docker (Nuxt + `@nuxtjs/mcp-toolkit` + Redis) на VM портала, снаружи — путь `/mcp-ai/` через nginx портала.

[`docs/DEPLOY_BITRIXVM.md`](docs/DEPLOY_BITRIXVM.md), все документы — [`docs/README.md`](docs/README.md).
