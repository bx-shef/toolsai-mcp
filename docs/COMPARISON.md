# Наш MCP-сервер и облачный MCP Битрикс24

> Last reviewed: 2026-10-14

Источник об облачном: [helpdesk 26952788](https://helpdesk.bitrix24.ru/open/26952788/) (обновлена
21.08.2026). Имён его инструментов в статье нет — точный список даст только `tools/list` после
подключения (план, шаг 12). Пометка «вывод» — не написано в источнике, наше предположение.

| | Облачный `mcp.bitrix24.tech` | Наш toolsai-mcp |
|---|---|---|
| Порталы | Облачные. Коробка в статье не упомянута, токен — в Паспорте Битрикс24 (вывод: коробке недоступен) | Любой Битрикс24: облако и коробка, адрес вводит сотрудник |
| Где сервер и данные | У Битрикс24 | Свой сервер: на VM портала или своём домене |
| Инструменты | Области: CRM (найти, создать, изменить, стадии, воронки), задачи (создать, изменить, чек-листы), структура, приглашения, почта (прочитать, отправить) | 9 узких, только чтение: сотрудник, сделки, лиды, контакты, компании, дела (с ИИ-резюме звонков), задачи |
| Запись | Есть; подтверждение запрашивает ИИ-ассистент (вывод: на стороне клиента) | Пока нет; план — подтверждение и журнал «было/стало» на сервере |
| Вход | OAuth или токен из «Приложения → MCP-подключения» в заголовке | OAuth сотрудника: свой сервер авторизации для клиента + OAuth Битрикс24 |
| Чьи права | Сотрудника | Сотрудника; ID сотрудника и портал берутся из токена, не из аргументов |
| Клиенты | Названы ChatGPT, Yandex AI Studio, Cursor, n8n | Любой MCP-клиент с OAuth 2.1 (claude.ai, Claude Code, ChatGPT, Cursor) |
| Кто допускается | Один переключатель на портал, по умолчанию выключен | `ALLOWED_USERS`: порталы, сотрудники порталов или все |
| Журнал | Не описан | Кто, портал, инструмент, имена аргументов, итог, время; без значений |
| Свои инструменты | Нет (вывод: закрытый сервис) | Да — `server/mcp/tools/` |
| Отзыв доступа | Паспорт → MCP-подключения → «Закрыть доступ» | Отзыв на портале или убрать из `ALLOWED_USERS`; своя страница — план, шаг 8 |
| Цена | .ru — подписка «BitrixGPT + Маркетплейс», другие зоны — коммерческий тариф | Свой хостинг; для многих порталов — приложение в партнёрском кабинете |

**Итог.** Облачный сильнее в записи и почте и не требует своего сервера. Наш нужен там, где
облачного нет или его мало: коробка, свои инструменты (звонки и оценки `shef.toolsai`), свой
список допуска и журнал, работа с несколькими порталами одним подключением сервера. Оба можно
держать в клиенте одновременно.
